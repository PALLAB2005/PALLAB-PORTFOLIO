## ⚡ Interactive Experience

The portfolio includes multiple interactive effects to create an engaging user experience.

### 🚀 Preloader Animation

A custom loading animation provides a smooth transition while the website initializes.

### 🎯 ScrollSpy Navigation

Navigation automatically highlights the section currently visible on the screen.

### 🧲 Magnetic Buttons

Buttons dynamically respond to cursor movement for a more interactive experience.

### 💡 Spotlight Hover Cards

Cards use dynamic spotlight effects when the user moves the cursor over them.

### 🌀 3D Tilt Project Cards

Project cards respond to mouse movement with a subtle 3D tilt effect.

### 🖼️ Parallax Images

Images move at different speeds during scrolling to create a layered visual effect.

### 👁️ Scroll Reveal Animations

Elements smoothly appear when entering the viewport using the **Intersection Observer API**.

### 🔔 Toast Notifications

Interactive toast notifications provide feedback to users.

### 🪟 Project Modal

Users can view additional project information through an interactive modal.
